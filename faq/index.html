Frequently Asked Questions

Quick answers about uploads, folders, privacy, and support.

Questions we hear most often

What is Klypp and how is my media handled?

The Klypp mobile app moves your private/authorized media from your phone to your self-hosted media server. A relay operated by Klypp LLC simply routes the encrypted transfer; it never stores or inspects the payloads. The files remain on your devices and the server you control. For more privacy details, see the Privacy page.

What Linux permissions helper should I run?

We publish a Linux Helper Script on the Downloads page that adjusts ownership/permissions for the klypp service user. Run that script once after installing to avoid “access denied” errors when the server scans your folders.

How should I configure FileSave, Incomplete, and Completed folders?

The recommended flow is: FileSaveLocation receives uploads from the mobile app, IncompletePath holds files while they are still being written, and CompletedPath is where Klypp picks up finished transfers to route them into Movies, TV, or Music destinations. Some torrent clients can use the same folder for incomplete and completed downloads, but separate folders are usually easier to manage.

Can I use Klypp with a torrent client?

Yes. Klypp can work with torrent clients that watch for new .torrent files and use incomplete and completed download folders. qBittorrent is one example; see the Torrent Client Setup guide for the recommended folder flow. Only use torrents for media you are legally authorized to download and share.

Why use File Completed Mover quiet hours?

Quiet hours let new files build in the Processing Queue without repeatedly waking a NAS during the day. When the mover resumes, Klypp processes the saved queue during your chosen window. See File Completed Mover and quiet hours for details.

How does Plex Media Sync avoid full library scans?

After a successful move, Klypp tells Plex exactly which movie, episode, or music album changed instead of relying on Plex's broad library scans or unreliable folder watching. Klypp then checks whether Plex lists the media and can notify you when it is ready to watch. This is especially helpful for large libraries. Klypp Drive Location paths must exactly match the library paths used by Plex on that server. See Plex Media Sync.

What can Klypp scripts run?

Klypp can run any command or script that the Klypp Server machine can run from the command line, subject to the permissions available to the Klypp service. Scripts can be run and scheduled from Klypp Server or the mobile app. See Scripts.

Can I split media by 4K and kids content?

Yes. Add paired destinations for TV/TV4K and Movie/Movie4K, and optionally KidsTV/KidsTV4K and KidsMovie/KidsMovie4K to override standard folders for family-friendly titles. The Advanced movie setups and TV setups sections show practical examples.

How does TV drive priority work?

The app scans your listed TV drives in priority order (1→N). If it finds the show on a drive while scanning, it keeps writing new episodes there. If the show is absent from every listed drive, the new show lands on the last (N) drive. Add new drives with higher numbers so older shows keep writing to their current location. See TV: Multiple Drives & Priority for the exact behavior.

What are common setup mistakes to avoid?

Typical issues: missing the three-folder flow (FileSave → Incomplete → Completed), letting CompletedPath receive uploads directly, forgetting to run the Linux helper (permissions), removing a TV drive mid-series (it splits your collection), or forgetting to mark destinations like Kids or 4K. Always verify CompletedPath is writable by the klypp user.

What permissions does the mobile app need?

The app requests access to Files/Photos to select uploads, Local Network (iOS) to discover servers, and optional Notifications for transfer status. You can revoke any permission later in your device settings.

How do I contact support or request data deletion?

Email support@klyppedit.com for help, and use the Delete Account page for the steps and timeline. If you can’t complete the button flow, reach out to privacy@klyppedit.com with your OS, KlyppServer version, and any repro details so we can assist.

What happens if the mover sees a .rar file?

Before the file moves, Klypp runs an unrar step so the archive is expanded and the contained media is processed instead of the compressed package.

What if my computer reboots while transfers are running?

We track every file in the database, so an interrupted transfer is remembered. When the box boots back up, Klypp resumes processing the queued files automatically.

Can I make one file jump ahead of a long queue?

Yes. Tap “Jump queue” from the mobile app or server UI and that file moves to the front of the processor so it runs next.
